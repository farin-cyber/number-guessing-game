# 🎯 Number Guessing Game

A beginner-friendly Python game where the computer chooses a random number between 1 and 100, and the player tries to guess it.

## ✨ Features

- Generates a random number
- Accepts user guesses
- Gives "Too high" or "Too low" hints
- Counts the number of attempts
- Ends when the correct number is guessed
- Includes a welcome message

## 🛠️ Built With

- Python
- Random module

## ▶️ How to Run

Run the `number_guessing_game.py` file and follow the instructions.
